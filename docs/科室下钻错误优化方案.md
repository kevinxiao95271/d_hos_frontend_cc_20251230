## ✅ 前端优化建议

### 优化1: 更友好的错误提示

**问题**: 直接显示"系统异常,请联系管理员"对用户不够友好

**改进方案**:

```javascript
} catch (error) {
  console.error('Failed to load dept drill down data:', error)

  // 更友好的错误提示
  const errorMsg = error.message || '未知错误'
  if (errorMsg.includes('系统异常')) {

    ElMessage.error('加载科室数据失败: ' + errorMsg)

}
```

## 🔧 完整的改进代码

### 1. 添加错误状态变量

```javascript
const deptDrillError = ref('')  // 新增: 错误消息
```

### 2. 修改openDeptDrill函数

```javascript
const openDeptDrill = async (metric) => {
  currentMetric.value = metric
  drillDownVisible.value = true
  drillLoading.value = true
  deptDrillError.value = ''  // 清空之前的错误

  try {
    // 调用后端API获取科室下钻数据
    const deptData = await indicatorResultApi.getDeptDrillDown({
      metricCode: metric.metricCode,
      timeDimension: queryForm.value.timeDimension,
      startDate: dateRange.value[0],
      endDate: dateRange.value[1]
    })

    // 如果后端返回了数据,使用后端数据
    if (deptData && Array.isArray(deptData) && deptData.length > 0) {
      deptDrillData.value = deptData
      deptDrillError.value = ''
    } else {
      // 如果后端没有数据,显示提示
      deptDrillData.value = []
      // 不设置错误,使用空数据提示
    }
  } catch (error) {
    console.error('Failed to load dept drill down data:', error)

    // 设置错误消息
    const errorMsg = error.message || '未知错误'
    if (errorMsg.includes('系统异常')) {
      deptDrillError.value = '科室下钻功能暂不可用,后端接口正在维护中'
    } else {
      deptDrillError.value = errorMsg
    }

    deptDrillData.value = []

    // 不弹出错误提示,在对话框内显示即可
    // ElMessage.error('加载科室数据失败: ' + errorMsg)  // 注释掉
  } finally {
    drillLoading.value = false
  }
}
```

### 3. 优化对话框模板

```vue
    >
      <!-- 表格列定义保持不变 -->

  </div>
</el-dialog>
```
