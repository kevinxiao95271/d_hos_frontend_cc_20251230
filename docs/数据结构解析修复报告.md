## 修复日期
2025-12-31

## 🎯 问题描述

### 用户反馈
"肺炎(住院、成人)病种例数 这个就不为零 指标项那边返回结果是有数据的。但是页面几乎所有指标计算结果全部都是0"

### 根本原因
后端API返回的数据结构与前端代码预期的结构不一致,导致数据提取失败,所有值都显示为0。

---

## 🔍 问题分析

### 后端实际返回的数据结构

#### 1. 指标计算API (`/api/indicator-result/calculate`)
**实际返回**:
```json
{
  "code": 200,
  "data": {
    "resultValue": 2,
    "resultJson": "{\"item_values\":{\"a0050\":2}}"
  }
}
```

#### 2. 指标项执行API (`/api/indicator-item/{itemCode}/execute`)
**实际返回**:
```json
{
  "code": 200,
  "data": {
    "result": {
      "result_value": 2
    }
  }
}
```

### 前端代码预期的数据结构

**之前代码预期**:
```javascript
// 预期1: 简单数字
result = 2

// 或预期2: 包含value字段的对象
result = { value: 2 }
```

**实际情况**:
- 指标计算返回: `{ resultValue: 2, resultJson: "..." }`
- 指标项执行返回: `{ result: { result_value: 2 } }`

**结果**: 由于字段名不匹配,`result.value` 和 `itemValue` 都是 `undefined`,最终显示为 0

## ✅ 修复方案

### 修复1: 指标项值提取

**文件**: [src/views/indicator-statistics/index.vue](src/views/indicator-statistics/index.vue#L319-L332)

**修复前**:
```javascript
const itemValue = await indicatorItemApi.execute(itemCode, {
  startDate: dateRange.value[0],
  endDate: dateRange.value[1]
})
itemDataMap[itemCode] = itemValue  // ❌ 直接赋值整个对象
```

**修复后**:
```javascript
const itemValue = await indicatorItemApi.execute(itemCode, {
  startDate: dateRange.value[0],
  endDate: dateRange.value[1]
})
// ✅ 从嵌套结构中提取真实值: { result: { result_value: 2 } }
itemDataMap[itemCode] = itemValue?.result?.result_value ?? null
```

### 修复2: 指标计算结果提取

**文件**: [src/views/indicator-statistics/index.vue](src/views/indicator-statistics/index.vue#L344-L349)

**修复前**:
```javascript
// ❌ 只查找 result.value

  finalValue = 0

```

**修复后**:
```javascript

  ? result.resultValue
  : (result.value !== undefined ? result.value : result)

  finalValue = 0
}
```

## 🔍 技术细节

### 可选的空值合并运算符 (`??`)

使用 `??` 而不是 `||` 来处理可能的0值:
```javascript
// ✅ 正确: 0值会被保留
itemDataMap[itemCode] = itemValue?.result?.result_value ?? null

// ❌ 错误: 0值会被替换为null
itemDataMap[itemCode] = itemValue?.result?.result_value || null
```

### 可选链操作符 (`?.`)

安全地访问嵌套属性:
```javascript
// ✅ 如果itemValue为null或undefined,不会报错
itemValue?.result?.result_value

// ❌ 如果itemValue为null或undefined,会报错
itemValue.result.result_value
```

### 多层回退逻辑

优先使用后端真实字段名,保持向后兼容:
```javascript
// 1. 优先使用 resultValue (后端实际字段)
// 2. 如果没有,尝试 value (兼容旧格式)
// 3. 如果都没有,使用 result 本身
const value = result.resultValue !== undefined
  ? result.resultValue
  : (result.value !== undefined ? result.value : result)
```
