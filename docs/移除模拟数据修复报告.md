## 🔍 数据流向验证

### 完整的数据流
```
1. 用户点击"查询"
   ↓
2. 加载指标树 (GET /api/indicator/tree)
   ↓
3. 收集所有末级指标
   ↓
4. 对每个指标:
   a. 调用指标计算API (POST /api/indicator-result/calculate)
      ↓ 获取指标值 (例如: 8391.08)

   b. 解析依赖的指标项 (例如: ["a0041", "a0046"])
      ↓
   c. 对每个指标项:
      调用指标项执行API (POST /api/indicator-item/{itemCode}/execute)
      ↓ 获取指标项值 (a0041: 1, a0046: 8391.08)

   d. 组装结果展示:
      指标值: 8391.08
      来源指标项:
        - a0041: 1 人
        - a0046: 8391.08 元
      计算公式: a0046/a0041

5. 用户点击"科室下钻"
   ↓
6. 调用科室下钻API (GET /api/indicator-result/dept-drill-down)
   ↓
7. 显示各科室的真实数据
```

## 📊 后端API要求

### 指标计算API
```
POST /api/indicator-result/calculate
参数:
  - metricCode: 指标编码
  - timeDimension: YEAR/MONTH/DAY
  - startDate: 开始日期
  - endDate: 结束日期

返回:
{
  "code": 200,
  "data": {
    "value": 8391.08,  // 指标计算结果
    "timestamp": "2025-12-31 12:00:00"
  }
}
```

### 指标项执行API
```
POST /api/indicator-item/{itemCode}/execute
参数:
  - startDate: 开始日期
  - endDate: 结束日期

返回:
{
  "code": 200,
  "data": 1  // 指标项值 (数字)
}
```

### 科室下钻API
```
GET /api/indicator-result/dept-drill-down
参数:
  - metricCode: 指标编码
  - timeDimension: YEAR/MONTH/DAY
  - startDate: 开始日期
  - endDate: 结束日期

返回:
{
  "code": 200,
  "data": [
    {
      "deptName": "心内科",
      "value": 5234.56,
      "percentage": 62.3,
      "sourceValues": {
        "a0041": 5,
        "a0046": 26172.8
      }
    },
    ...
  ]
}
```
