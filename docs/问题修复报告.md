## 修复的问题

### 1. ✅ 指标计算返回0应判断为成功

**问题描述**:
当指标计算结果为0时,被错误地判断为失败状态。

**影响范围**:
[指标计算](src/views/indicator-calculation/index.vue) 页面

**修复位置**:
`src/views/indicator-calculation/index.vue` 第196-218行

**修复前代码**:
```javascript
try {
  const result = await indicatorResultApi.calculate({...})

  item.status = 'success'
  item.result = result.value !== undefined ? result.value : '计算完成'
  item.message = '计算成功'
} catch (error) {
  item.status = 'failed'
  item.message = error.message || '计算失败'
}
```

**修复后代码**:
```javascript
try {
  const result = await indicatorResultApi.calculate({...})

  // 判断计算成功: result不为null/undefined即为成功,包括值为0的情况
  if (result !== null && result !== undefined) {
    item.status = 'success'
    const value = result.value !== undefined ? result.value : result
    // 处理 NaN (0/0的结果)
    item.result = isNaN(value) ? 0 : value
    item.message = '计算成功'
  } else {
    item.status = 'failed'
    item.message = '计算结果为空'
  }
} catch (error) {
  item.status = 'failed'
  item.message = error.message || '计算失败'
}
```

**修复说明**:
- ✅ 明确判断 `result !== null && result !== undefined`,包括值为0的情况
- ✅ 添加NaN处理,0除以0的结果转为0
- ✅ 改进错误消息提示

### 2. ✅ 0除以0的结果处理为0

**问题描述**:
当计算表达式出现0除以0时,结果为NaN,导致显示异常。

**影响范围**:
- [指标计算](src/views/indicator-calculation/index.vue) 页面
- [指标统计看板](src/views/indicator-statistics/index.vue) 页面
- [全局请求拦截器](src/utils/request.js)

**修复位置**:
1. `src/views/indicator-calculation/index.vue` 第209行
2. `src/views/indicator-statistics/index.vue` 第343-347行
3. `src/utils/request.js` 第28-38行

**修复内容**:

#### 2.1 指标计算页面
```javascript
// 处理 NaN (0/0的结果)
item.result = isNaN(value) ? 0 : value
```

#### 2.2 统计看板页面
```javascript
// 获取结果值,处理NaN情况
let finalValue = result.value !== undefined ? result.value : result
if (isNaN(finalValue)) {
  finalValue = 0
}
```

#### 2.3 全局请求拦截器
```javascript
// 处理返回数据中的NaN值
let data = res.data
if (data !== null && typeof data === 'object') {
  // 如果data有value字段且为NaN,转为0
  if (data.value !== undefined && (data.value === null || isNaN(data.value))) {
    data.value = 0
  }
} else if (data !== null && isNaN(data)) {
  data = 0
}
```

### 3. ✅ 统计看板查询不到数据的问题

**问题描述**:
在指标统计看板页面,按年、按月或按日查询时看不到数据。

**根本原因**:
1. 之前使用随机数生成模拟数据,导致数据不一致
2. 缓存判断逻辑错误: `!itemDataMap[itemCode]` 会把值为0的情况也当作未缓存
3. 缺少详细的成功/失败统计信息

**影响范围**:
[指标统计看板](src/views/indicator-statistics/index.vue) 页面

**修复位置**:
`src/views/indicator-statistics/index.vue` 第269-373行

**修复内容**:

#### 3.1 修复缓存判断
**修复前**:
```javascript
if (!itemDataMap[itemCode]) {
  // 这会把值为0的情况也当作未缓存!
  const itemValue = await indicatorItemApi.execute(...)
  itemDataMap[itemCode] = itemValue
}
```

**修复后**:
```javascript
if (itemDataMap[itemCode] === undefined) {
  // 只有真正未定义时才获取
  const itemValue = await indicatorItemApi.execute(...)
  itemDataMap[itemCode] = itemValue
}
```

#### 3.2 添加进度提示
```javascript
ElMessage.info(`正在计算 ${leafMetrics.length} 个指标,请稍候...`)
```

#### 3.3 添加成功/失败统计
```javascript
let successCount = 0
let failCount = 0

// ... 计算过程 ...

ElMessage.success(`加载完成! 成功: ${successCount}, 失败: ${failCount}`)
```

#### 3.4 改进错误处理
```javascript
ElMessage.error('加载失败: ' + (error.message || '未知错误'))
```
